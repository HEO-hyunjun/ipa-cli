> IPA CLI 2차 구현의 주간 우선순위와 blocker를 확인한 스크럼 기록.

## 합의

- 이번 주에는 P3 Convention Runtime 검증을 먼저 끝내고 P4 Search Runtime alias·parents 검색 검증까지 연결한다.
- P5 Parser Layer의 code fence와 embed edge case는 다음 스프린트로 미룬다.

## 진행 상황

- P1 API 표면과 P2 Mapping Layer fixture는 완료했다.
- P3의 vault-scope rule 검증이 진행 중이다.

## Blocker

- divergent profile의 `kind/parents` mapping fixture가 기본 `type/ref` 구현과 섞이면 P3 결과를 신뢰할 수 없다. mapping fixture를 고정한 뒤 convention 검증을 재실행한다.
